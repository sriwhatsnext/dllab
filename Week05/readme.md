## Dataset

**Oxford-IIIT Pet Dataset**

* **Rows:** 7,349 images
* **Image Size:** Varying image dimensions (images are resized during preprocessing)
* **Channels:** 3 (RGB)
* **Target Classes:** 37 (different cat and dog breeds)
